# B01b — Relações simétricas

**Data:** 2026-11-14  
**Commit:** (a ser gerado)

## O que mudou

- `RelationType` ganhou campo `symmetric: bool = False`.
- `claim_key` em `core/ids.py` aceita parâmetro keyword `symmetric: bool = False`.
  Quando `True`, `subject_id` e `object_id` são ordenados lexicograficamente
  antes do hash — A→B e B→A produzem a mesma chave.
  Tipos não simétricos têm comportamento idêntico ao anterior.
- ADR 003 atualizado com a semântica da chave simétrica.
- Schema `contracts/schemas/relation-type.json` regenerado (campo `symmetric` adicionado).
- 3 novos testes em `tests/test_core_models.py`:
  - `test_claim_key_symmetric_ab_eq_ba`
  - `test_claim_key_nonsymmetric_ab_neq_ba`
  - `test_claim_key_nonsymmetric_unchanged`

## Como testar

```
make check   # 180 testes, lint e typecheck
```

## Pendências

Nenhuma. O campo `symmetric` ainda não é usado pelo pipeline de extração
(B03/B05), mas o contrato de upsert já está correto.
